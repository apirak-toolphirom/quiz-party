# 🎉 Quiz Party

เกมตอบคำถามแข่งกันสด ๆ สไตล์ Kahoot สำหรับห้องเรียน/งานอบรม — ผู้เล่นสแกน QR ด้วยมือถือ ตั้งชื่อ เลือกตัวละคร แล้วแข่งตอบพร้อมกันแบบเรียลไทม์

## ความสามารถ

- **สร้าง/แก้ไขแบบทดสอบ** บนเว็บ: คำถาม 2–4 ตัวเลือก, ทำเป็นถูก/ผิดได้, ตั้งเวลาแต่ละข้อ 5–120 วินาที, ข้อคะแนน x2
- **แนบภาพและเสียง** ให้คำถาม (อัปโหลดไฟล์ หรือ 🎙 อัดเสียงจากไมค์ได้เลย)
- **QR code + PIN 6 หลัก** สแกนเข้าห้องทันที ตั้งชื่อเล่นและเลือกอวาตาร์ได้ (ชื่อซ้ำไม่ได้)
- **กำหนดจำนวนข้อ** ที่จะใช้เล่น และสุ่มลำดับ/สุ่มเลือกข้อได้
- **คะแนน**: ตอบถูกได้ 500–1,000 คะแนน ยิ่งตอบเร็วยิ่งได้มาก (ข้อ x2 ได้สองเท่า) ตอบผิด/ไม่ตอบได้ 0
- **🐢 โหมดรอเพื่อน**: ใครตอบ *ถูกและเร็ว* ติดกันครบ 3 ข้อ (ปรับได้) จะโดน **หัก 100 คะแนน** (ปรับได้) แล้วเริ่มนับใหม่ — ให้เพื่อนตามทัน เพิ่มความลุ้น
  - "เร็ว" = ตอบภายใน 50% ของเวลาข้อนั้น (ปรับได้ในหน้าตั้งค่า)
  - มือถือผู้เล่นแสดงสายฟ้า ⚡ นับว่าใกล้โดนหักหรือยัง
- จอใหญ่: นับถอยหลัง, จำนวนคนตอบ, กราฟเฉลย, คนตอบเร็วสุด, ตารางคะแนน, แท่นรับรางวัล + พลุกระดาษ
- ดาวน์โหลดผลเป็น **CSV** (เปิดใน Excel ภาษาไทยได้)
- เสียงเอฟเฟกต์และเพลงล็อบบี้สังเคราะห์ในเบราว์เซอร์ ไม่ต้องมีไฟล์เสียง
- เน็ตหลุด/รีเฟรชหน้า กลับเข้าห้องเดิมได้ทั้งผู้จัดและผู้เล่น

## ติดตั้ง

### Node.js (18 ขึ้นไป)
```bash
git clone https://github.com/apirak-toolphirom/quiz-party.git
cd quiz-party
npm install
PUBLIC_URL=http://192.168.1.50:3000 npm start
```

### Docker
```bash
# แก้ PUBLIC_URL / HOST_KEY ใน docker-compose.yml ก่อน
docker compose up -d --build
```

เปิด `http://<IP เครื่อง>:3000/host.html` บนเครื่องที่ต่อโปรเจกเตอร์ → เลือกแบบทดสอบ → ▶ เล่น → ตั้งค่า → 🚀 สร้างห้องเกม

> ⚠️ ถ้าเปิดหน้าผู้จัดด้วย `localhost` ลิงก์ใน QR จะเป็น localhost ซึ่งมือถือเข้าไม่ได้ ให้เปิดด้วย IP เครื่อง หรือกำหนด `PUBLIC_URL`
>
> การอัดเสียงจากไมค์ต้องเปิดผ่าน `https://` หรือ `localhost` (ข้อกำหนดของเบราว์เซอร์) ส่วนอัปโหลดไฟล์เสียงใช้ได้เสมอ

## ตัวแปรสภาพแวดล้อม

| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | `3000` | พอร์ตเว็บ |
| `PUBLIC_URL` | (ว่าง) | URL ที่ใส่ใน QR เช่น `https://quiz.example.ac.th` ถ้าว่างจะใช้ URL ที่ผู้จัดเปิดอยู่ |
| `HOST_KEY` | (ว่าง) | รหัสผู้จัด — ถ้าตั้งไว้ ต้องใส่รหัสก่อนสร้าง/แก้แบบทดสอบและเปิดห้อง |
| `DATA_DIR` | `./data` | ที่เก็บแบบทดสอบ (`quizzes/*.json`) และไฟล์ภาพ/เสียง (`uploads/`) |
| `MAX_PLAYERS` | `300` | จำนวนผู้เล่นสูงสุดต่อห้อง |

## โครงสร้าง

```
server.js          Express + Socket.IO: API แบบทดสอบ, อัปโหลด, QR, ตรรกะเกมและคะแนน
public/
  index.html       หน้าแรก (เลือก เล่น / ผู้จัด)
  host.html/.js    คลังแบบทดสอบ, ตัวแก้ไข, ตั้งค่า, ล็อบบี้ QR, จอเกม
  play.html/.js    หน้าผู้เล่นบนมือถือ
  common.js        เสียงเอฟเฟกต์, พลุ, ตัวจับเวลา
  style.css        ธีมสีสดใส
samples/           แบบทดสอบตัวอย่าง (คัดลอกเข้า data ครั้งแรก)
test/game-test.js  ทดสอบการไหลของเกม + โหมดรอเพื่อน (npm test)
```

## รูปแบบไฟล์แบบทดสอบ (นำเข้า/ส่งออก JSON)

```json
{
  "title": "ชื่อแบบทดสอบ",
  "questions": [
    { "text": "คำถาม", "image": "/uploads/xxx.png", "audio": "", "options": ["ก", "ข", "ค", "ง"], "correct": 1, "time": 20, "double": false }
  ]
}
```
`correct` คือลำดับตัวเลือกที่ถูก เริ่มจาก 0

## สูตรคะแนน

```
ตอบถูก:  คะแนน = round(1000 × (1 − เวลาที่ใช้ / เวลาทั้งหมด / 2)) × (2 ถ้าเป็นข้อ x2)
โหมดรอเพื่อน: ถ้า ถูก+เร็ว ติดกันครบ N ข้อ → หัก P คะแนน แล้วนับใหม่ (คะแนนไม่ติดลบ)
```
